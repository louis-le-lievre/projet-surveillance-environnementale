# Projet de surveillance environnementale

## Présentation

Projet réalisé en équipe dans le cadre de notre formation d'ingénieur à l'EPF. L'objectif est de mesurer différents paramètres environnementaux à l'aide de capteurs et de visualiser les données sur une interface web.

## Fonctionnalités

- Mesure de la température et de l'humidité
- Surveillance de la qualité de l'air, du bruit, de la luminosité et de la pression atmosphérique
- Transmission des données entre une Arduino Mega et un NodeMCU
- Affichage des mesures sur une interface web
- Déclenchement d'alertes selon des seuils prédéfinis

## Technologies

- Arduino Mega et NodeMCU ESP8266
- C/C++
- HTML, CSS et JavaScript
- JSON, Wi-Fi et WebSocket

## Organisation

- `arduino/` : programmes des cartes électroniques
- `web/` : interface web

## Contexte

Projet de mécatronique réalisé en équipe à l'EPF.
